Rules and keys

Each layer has its own block: tag every error you see (yes for any clear error, however small), then give the verdict for the satellite product. OK is set automatically when no error is flagged in the layer; a layer with a flagged error is minor or major. Minor, keep: errors exist but would not noticeably change the satellite cover here. Major, exclude: all errors in this layer together would noticeably bias the satellite cover here. Lying wood is never deadwood; standing dead trees are forest.

Work top to bottom: 1/2/3 answer the highlighted row and move down; after the last row it goes to the next crop. Space marks the current layer fine (all no, verdict OK) and jumps to the next block. ↑/↓ or a click pick a row. Enter remaining questions = no (a layer without any yes also gets OK), next. c can't tell. Tab next open crop, ←/→ previous/next. Wheel and drag zoom, double-click resets.
